## Repo rules

- Migrations only with `dotnet ef migrations add <Nome>`; never written or edited by hand.
- MySQL provider: `MySql.EntityFrameworkCore` 10.0.x. Do not use Pomelo (stuck at EF Core 9, unsupported).
- No generic repository: `DbContext` used directly in feature services.
- Integration tests on Testcontainers MySQL; SQLite only for pure logic.
- OpenAPI contract generated by the backend; the frontend consumes it.
- Secrets only via user-secrets in development or a secret manager; never in `appsettings`.
- Remote audit redacted: no secrets in plaintext.
- RBAC D7 = B: global master data `SystemAdmin`; environment resources `ServerAdmin` on all involved environments; `SystemAdmin` is not enough for server/console/run.
- Menu filtered by `MenuRole`; CSRF on all mutations.
- Session cookie: HttpOnly, `SameSite=Lax`, `Secure` in production; no token in the response.
